# Analysis

## What the power-law claim rests on

The result in [S001] depends on an assumption it does not state: that the ranges measured
are representative of the ranges anyone cares about. Observing no ceiling within a budget
is not the same as demonstrating there is none; it establishes only that the experiment
stopped before finding one. The practical question is where the knee sits, and an
extrapolation cannot locate a knee outside its own sampling window.

## Conflict between [S001] and [S002]

These disagree about whether parameter count predicts capability. The disagreement is
**empirical** and a single controlled run at matched parameter counts, with published
methodology, would settle it. Weight matters here: [S001] is peer-reviewed with released
data, while [S002] is a vendor describing its own product without disclosing method.
